# Computer Algorithms Lab

A collection of algorithm implementations developed as part of the Computer Algorithms Lab. This repository contains different problem-solving techniques and algorithmic approaches implemented using C++ and Python.

## Overview

Algorithms are fundamental techniques used to solve computational problems efficiently. This repository contains implementations of various algorithms covered in the Computer Algorithms course, including sorting, divide and conquer, greedy algorithms, dynamic programming, and optimization techniques.

The main purpose of this repository is to understand algorithm design techniques, analyze problem-solving approaches, and implement algorithms using programming languages.

## Algorithms Implemented

## Sorting Algorithms

Sorting algorithms are used to arrange data elements in a specific order.

Implemented algorithms:

- Bubble Sort
- Insertion Sort
- Quick Sort

Folder:

```
Sorting/
```

## Maximum Sum Subarray

The Maximum Sum Subarray problem finds the contiguous subarray with the maximum possible sum.

Implemented approaches:

- Brute Force Method
- Divide and Conquer Method

Folder:

```
Maximum Sum Subarray/
```

## Greedy Algorithms

Greedy algorithms solve optimization problems by making locally optimal choices at each step.

Implemented algorithms:

- Activity Scheduling
- Car Fueling Problem
- Huffman Coding
- Knapsack Problem


# How to Run

## Clone the Repository

```bash
git clone https://github.com/afiaislam/ComputerAlgorithms_Lab.git
```

## Navigate to the Repository

```bash
cd ComputerAlgorithms_Lab
```

## Run Python Files

Example:

```bash
python QuickSort.py
```

## Run C++ Files

Compile and run C++ files using:

```bash
g++ filename.cpp -o output
./output
```
